El Refugio

Una tienda de muebles de jardín donde primero se confirma el pedido, después se cotiza el flete y recién entonces se cobra.

Rol
Análisis, diseño y desarrollo individual
Estado
Puesta en producción pendiente
Tecnologías
PHP 8.4, Laravel 13, MySQL, Blade, Tailwind CSS 4, HTMX, Mercado Pago Checkout Bricks, PHPUnit

Cotizar el expreso antes de cobrar

El Refugio es una forrajería de Olavarría que quería vender muebles de jardín a todo el país. Como el expreso se cotiza para cada pedido, el costo de envío se confirma después de recibir el pedido. El comercio se comunica por WhatsApp, carga la cotización y habilita un link de pago cuando el cliente acepta el total.

El cliente puede usar el carrito como invitado, confirmar el pedido con correo verificado y seguirlo desde la tienda. Para retirar en el local, el carrito abre WhatsApp con el pedido escrito. El link de pago funciona sin iniciar sesión y ofrece crédito en cuotas, débito o dinero en cuenta.

Confirmar el pago y conservar el historial

Con Checkout Bricks, el servidor fija el importe y la cantidad de cuotas en cada intento. Si alguno difiere, rechaza el intento. El precio se calcula dividiendo el total por uno menos la tasa de la modalidad y redondeando hacia arriba. Con una tasa del 20 %, el cliente abona $125.000 para que el negocio reciba $100.000.

El backend verifica la firma del webhook y vuelve a consultar a Mercado Pago para comprobar referencia, importe, moneda, medio y cuotas. La idempotencia evita duplicados y una tarea concilia pagos cada 15 minutos. Si se aprueba un pago para un pedido cancelado o reemplazado, el panel lo envía a revisión.

Pedido, contacto, pago y envío tienen estados separados. Cada pedido guarda los precios y datos al momento de la compra. Los aumentos masivos se previsualizan, se aplican en una transacción si los precios siguen coincidiendo y quedan asentados en el historial.

Un panel para el trabajo de todos los días

La bandeja de pedidos indica a quién contactar, qué cotizar, qué espera pago y qué hay que despachar. El comercio edita productos, precios y contenido del inicio desde el panel. El catálogo tiene buscador, categorías, ofertas, variantes de color e indica qué está agotado.

La gráfica toma las etiquetas colgantes del local para destacar títulos y precios. Usé tipografía legible, contraste alto y áreas de toque amplias tanto para quienes compran desde el celular como para quien atiende la tienda.

Qué hice

Definí las reglas de venta con el comercio, escribí la especificación, diseñé la interfaz y armé el modelo de datos. Organicé la lógica del negocio en servicios y validé las entradas con Form Requests. Implementé el sistema módulo por módulo con Claude Code y más de 300 pruebas sobre MySQL, empezando por el backend y siguiendo por las pantallas. También implementé las colas de conversión a WebP y correo, y la auditoría de acciones sensibles del panel.
