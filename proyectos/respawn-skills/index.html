Dejar por escrito el trabajo de cada etapa

En los proyectos de Respawn se repiten tareas como relevar el alcance, acordar el diseño y revisar el sitio antes de entregar. Armé una guía para cada etapa con preguntas, plantillas y criterios de revisión que se pueden volver a usar.

Empaqueté esas guías como skills compatibles con el estándar Agent Skills para que Claude Code pueda consultar las instrucciones de la etapa en la que estoy trabajando.

Separar las guías de las decisiones de cada cliente

El repositorio central guarda las reglas y plantillas comunes. Al iniciar un proyecto, se copia una versión de las skills al repositorio del cliente y se crea un espacio separado para el alcance, las decisiones y los pendientes.

Así cada proyecto funciona con su propia copia en cualquier equipo. Puedo actualizar las guías cuando hace falta y conservar el registro de lo que ya acordé con el cliente.
